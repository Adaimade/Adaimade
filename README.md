---

### 🦀 Rust Projects

#### ⚡ [RustClaw](https://github.com/Adaimade/RustClaw)

A lean Rust replacement for OpenClaw — 6 MB single binary, 7.9 MB idle memory, sub-100ms startup. WebSocket gateway, Telegram/Discord channels, agentic tool calling, cron scheduling, auto-PR from GitHub issues. Every line generated by Claude Code.

#### 🧠 [R-Mem](https://github.com/Adaimade/R-Mem)

Long-term memory for AI agents, in Rust. Vector memory + graph memory + history, all backed by SQLite in a single 3.2 MB binary. 1,748 lines of Rust, no external services, under 10 MB idle RSS.

### 🧪 Small Things I Made

#### ⚰️ [Digital Graveyard](https://github.com/Adaimade/digital-graveyard) — [Visit](https://digital-graveyard.zeabur.app)

A minimalist, 8-bit memorial for abandoned software projects. Create pixel tombstones, get AI-generated eulogies, mourn with philosophical quotes. Flask + Gemini AI.

> *"The code compiles. The tests pass. But the project... sleeps."*

#### ⚠️ [Project_SystemAlert](https://github.com/Adaimade/Project_SystemAlert)

Solo Leveling-inspired SVG status card for GitHub profiles. Turns your stats into an RPG card — level, STR, INT, job class, skill rankings. Has a hidden lobster evolution mechanic because why not.

![System Alert Card](https://project-systemalert.zeabur.app/api/card?username=Adaimade)

#### 🖥️ [systemee](https://github.com/Adaimade/systemee)

macOS menu bar monitor. CPU, memory, disk — click for details. Swift, no network calls, no data collection. Just a tiny eagle eye on your system.
